# Android-порт RG2 Desktop: каналы распространения

Проверено **14 ноября 2026** по официальным страницам владельцев платформ. «Бесплатно» ниже означает отсутствие обязательного регистрационного/публикационного взноса магазина, а не бесплатные реклама, облачные сервисы или банковские операции. Аккаунты не создавались, соглашения не принимались, формы и APK не отправлялись. Доступность конкретного аккаунта из РФ без авторизации и проверки документов не подтверждена.

**Практический порядок:** GitHub APK/PWA как прямые каналы; затем **RuStore → Uptodown → AppGallery**, после подтверждения прав на материалы и регистрации владельца. **GetApps** — следующий условно достижимый канал. **Galaxy Store** требует более сложного одобрения продавца. **Google Play не бесплатен**, **Amazon закрыт для обычных Android-телефонов**. F-Droid возможен после отдельного аудита лицензий и сборки.

## WebView, подпись и внешние зависимости порта

- **WebView сам по себе не запрещён.** RuStore прямо требует добавленную функциональность, например offline; Uptodown отклоняет низкокачественные обёртки сайтов; Google запрещает несанкционированные webviews и приложения без полезной функциональности. Для нашего продукта библиотека внутри APK, локальный поиск, таймер, тренажёры, решатель и сохранение состояния — содержательные отличия от простого открывания сайта, но это **аргумент для модерации, не гарантия допуска**. [RuStore §8.2](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps), [Uptodown criteria](https://support.uptodown.com/hc/en-us/articles/360052792972-Uptodown-s-app-publication-criteria), [Google policy](https://support.google.com/googleplay/android-developer/answer/18265346?hl=en).
- Для Huawei проверены общие [review guidelines](https://developer.huawei.com/consumer/en/doc/app/50104-overview/); отдельного подтверждённого общего запрета Android WebView не найдено. Для Samsung/GetApps нельзя выводить отсутствие специальных ограничений только из успешной загрузки APK; финальную submission checklist надо пройти в аккаунте.
- Практический базовый артефакт для альтернативных каналов — **universal release APK**, собственный новый applicationId и постоянный ключ подписи. Все Android APK должны быть подписаны; debug/testOnly build не является магазинным релизом. Ключ хранить вне публичного Git с резервной копией. Для AAB заранее решить, чей app-signing key использует каждый магазин: upload key и ключ конечного APK могут различаться. [Android signing](https://developer.android.com/studio/publish/app-signing), [release preparation](https://developer.android.com/studio/publish/preparing).
- Android-порт не должен тащить Windows .NET/WebView2. Для локального HTML/JS подходит системный Android WebView + AndroidX WebKit/WebViewAssetLoader с HTTPS-origin; Google рекомендует этот путь вместо небезопасного file://-доступа. [Load in-app content](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content?hl=en). WebGL2, ES modules и Workers нужно проверить на целевых WebView/устройствах.
- Для бесплатной offline-версии без рекламы/покупок/учётных записей можно проектировать сборку без GMS/HMS, vendor analytics и платёжных SDK. Это архитектурный вывод, а не обещание одобрения. RuStore предлагает выбирать только нужные [инструменты](https://www.rustore.ru/developer/en/tools); GetApps требует IAP-интеграцию именно при наличии IAP в [publication guide](https://orig-global.developer.mi.com/document?doc=appManagement.createAndUpdate). Проверить фактические Gradle dependencies; для F-Droid недопустимые proprietary SDK требуют отдельного FLOSS flavour.
- Нужны реальные мобильные скриншоты, описание на русском, support e-mail, privacy URL и честная декларация данных/разрешений. Offline не означает, что обращения к GitHub/YouTube и стороннему браузеру можно не учитывать в описании поведения.

## Отдельное ограничение Android developer verification 2026–2027

С **30.09.2026** проверка действует для participating stores на сертифицированных Android 7+ в Бразилии, Индонезии, Сингапуре и Таиланде; глобальное расширение заявлено на 2027 год. РФ не указана в начальной четвёрке. Это не означает, что любые APK во всех странах уже запрещены. [Текущий rollout](https://developer.android.com/developer-verification).

Для стандартной широкой дистрибуции вне Play **Android Developer Console Full тоже требует $25**. Бесплатный Limited — только до 20 разрешённых устройств, а не массовый релиз. Остаётся путь advanced flow для неподтверждённых приложений. Поэтому «бесплатный магазин» и «никаких расходов/верификации во всех странах» — разные обещания. [Стоимость ADC](https://support.google.com/android-developer-console/answer/16604405?hl=en), [планы](https://support.google.com/android-developer-console/answer/16640817?hl=en). Open-source repository не даёт автоматического освобождения: для обычного install flow руководство всё равно требует verified ADC/Play account. [Open-source registration, обновлено 23.10.2026](https://developer.android.com/developer-verification/guides/open-source-app-registration).

## Блокеры аккаунтов

1. Нужен подтверждённый владелец publisher accounts и его реальные контакты/страна/документы. Аккаунт магазина, Android signing key и право владения package — разные вещи. Без входа можно подготовить артефакты и карточки, но нельзя заявить «опубликовано».
2. RuStore/Uptodown требуют доступа к почте/телефону; Huawei — identity/bank documents; Samsung — commercial seller и финансовую/бизнес-проверку; Xiaomi — developer/ownership verification. Нельзя придумывать зарубежную страну, банк, компанию или обходить санкционную проверку.
3. Google Play и ADC Full не входят в полностью бесплатный сценарий нового аккаунта. Не оплачивать и не принимать юридические соглашения без действий/разрешения владельца.
4. Обязательны backup ключа и зафиксированная стратегия AAB/app-signing. При потере совместимого ключа обновление уже установленных APK может стать невозможно.

## Блокеры прав на контент и идентичность

**Уточнение после проверки исходников:** официальный [Tohaman/RG2.kotlin](https://github.com/Tohaman/RG2.kotlin) содержит Apache-2.0 (`Copyright Rozov Anton`). В версии 2020 года найдены совпадения содержания442 из505 уникальных материалов APK, включая423 из486 HTML-уроков. Из2063 PNG точных SHA256-совпадений нет: исходник хранит в основном XML-вектора;1671 картинка имеет кандидата с тем же basename, что ещё не доказывает точную конверсию. Проверка сохранила лицензии, архивы и пофайловое сопоставление в `work/mobile-source-license-audit/REPORT.md`. **Лицензия на всю более позднюю APK-версию этим не подтверждена:** остаются63 изменённых HTML-урока, точное происхождение растровых схем/добавленных картинок, брендинг и независимые сторонние импорты. Указание автора само по себе не закрывает эти вопросы. RuStore может запросить документы, Uptodown принимает автора либо обладателя distribution rights, F-Droid требует лицензий всех assets. [RuStore IP requirements](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps), [Uptodown](https://support.uptodown.com/hc/en-us/articles/360052792972-Uptodown-s-app-publication-criteria), [F-Droid](https://f-droid.org/en/docs/Inclusion_Policy/).

В осмотренном `work/desktop-shell` не найден корневой LICENSE/COPYING проекта; найден MIT-текст Three.js. Это означает, что **F-Droid-ready статус пока не доказан**, а не вывод о том, что разрешения нигде не существует. Нужен аудит оригинальной лицензии/согласия и совместимости всех зависимостей, затем выбор лицензии нашего кода. Новая идентичность и package должны отличать порт от оригинала; нельзя заявлять его официальным без соответствующих полномочий.

Практическая граница результата: **готовый подписанный Android-пакет + подготовленные карточки** можно сделать до входа владельца. **Публичный релиз в каждом конкретном магазине** подтверждается только его прошедшей модерацией карточкой и действующей публичной ссылкой — не числом заполненных форм.
