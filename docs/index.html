RG2 Mobile

Самостоятельная сборка виртуальных кубов 2×2–50×50, пирамид и додекаэдров 2–20. Свайпы поворачивают слои, два пальца управляют камерой. Подсказки рассчитываются по текущей позиции.

Вся прежняя библиотека алгоритмов, тренажёры и решатель по раскраске работают без интернета. Atelier, Graphite и тема устройства.
